# 比亚迪股票价格走势分析与可视化（2023-2026）

## 1. 任务与数据范围

本报告对应教材 P92 实战演练。原始 Excel 提供 2023-01-03 至
2023-12-29 的比亚迪日频后复权行情，共 242 个交易日。为完成扩展要求，
使用东方财富历史行情接口补采 2024-01-01 至 2026-10-27 的数据。

最终样本：

| 项目 | 内容 |
|---|---|
| 证券 | 比亚迪（002594.SZ） |
| 频率 | 日频 |
| 价格口径 | 后复权（东方财富 `fqt=2`） |
| 起始日期 | 2023-01-03 |
| 截止日期 | 2026-10-27 |
| 交易日数 | 922 |
| 2026 年口径 | 截至 2026-10-27 的年内数据 |

2023 年原表与新接口重合 242 行。开盘、收盘、最高、最低、成交量、
成交额、振幅、涨跌幅、涨跌额和换手率的最大绝对差异均为 0，交易日历
完全一致，说明新旧数据可以直接合并。

## 2. 金融场景理解

比亚迪同时覆盖新能源汽车、动力电池和电子制造，股票价格既反映企业
经营预期，也受到行业渗透率、产品周期、价格竞争、原材料成本、政策与
资本市场风险偏好的共同影响。因此，本任务不把单日涨跌直接解释为单一
事件，而将分析拆成四个层次：

1. **方向**：长期收盘价与年度收益回答价格朝哪里走。
2. **节奏**：K 线、月度和年度收益描述上涨、回调和反弹的阶段性。
3. **风险**：年化波动率、最大回撤和回撤持续区间衡量持有体验。
4. **确认**：MA20/60/120、RSI14 与成交量用于判断趋势是否得到延续。

后复权价格把分红送转和除权除息的影响连续化，适合做跨年度收益和均线
比较。若混用不复权价格，除权日会出现非经济意义的跳空，导致收益率和
最大回撤被误读。

## 3. 指标口径

| 指标 | 计算方式 |
|---|---|
| 区间收益 | 区间末收盘价 / 区间首个收盘价 - 1 |
| 年度收益 | 期末收盘 / 上年末收盘 - 1；2023 年以首个交易日收盘为基准 |
| 年化波动率 | 日收益率样本标准差 × √252 |
| 最大回撤 | 后复权收盘价相对此前运行峰值的最大跌幅 |
| MA20/60/120 | 20/60/120 日简单移动平均 |
| RSI14 | 14 日 Wilder 平滑相对强弱指标 |
| 日胜率 | 上涨交易日 /（上涨交易日 + 下跌交易日） |
| 成交量 | 手；图表中换算为万手 |
| 成交额 | 元；图表和统计中换算为亿元 |

## 4. 核心结果

### 4.1 全区间概览

| 指标 | 结果 |
|---|---:|
| 2023 首个交易日收盘 | 261.73 元 |
| 2026-10-27 收盘 | 256.57 元 |
| 全区间收益 | -1.97% |
| 年化波动率 | 30.80% |
| 最大回撤 | -44.56% |
| 最大回撤峰值日 | 2023-02-01 |
| 最大回撤低点日 | 2024-02-02 |
| 区间最高价 | 422.47 元（2025-05-23） |
| 区间最低价 | 165.17 元（2024-02-05） |
| 上涨 / 下跌交易日 | 426 / 495 |
| 日胜率 | 46.25% |
| 日均换手率 | 1.16% |

全区间首尾收益只有 -1.97%，但这并不代表四年间波动很小。价格期间从
165.17 元升至 422.47 元，又回落至 256.57 元。单看首尾会遗漏中间的大幅
上涨、深度回撤和多次趋势反转，因此必须结合路径、回撤和波动指标。

### 4.2 年度表现

| 年份 | 期末收盘 | 年度涨跌 | 年内最高 | 年内最低 | 成交额（亿元） | 日均换手率 |
|---|---:|---:|---:|---:|---:|---:|
| 2023 | 200.40 | -23.43% | 307.38 | 185.25 | 6,866.82 | 0.98% |
| 2024 | 288.15 | +43.79% | 343.53 | 165.17 | 7,535.09 | 1.10% |
| 2025 | 302.63 | +5.03% | 422.47 | 267.70 | 12,594.79 | 1.34% |
| 2026 YTD | 256.57 | -15.22% | 344.93 | 242.27 | 7,957.24 | 1.24% |

2023 年收跌，2024 年出现接近 44% 的年度反弹，2025 年虽然创出完整区间
最高价，但年末仅收涨约 5%，显示年内冲高回落明显。2026 年截至
2026-10-27 回撤 15.22%。2025 年成交额和日均换手率均为四年最高，反映
分歧和交易活跃度显著放大。

### 4.3 趋势与最新状态

截至 2026-10-27：

| 指标 | 数值 |
|---|---:|
| 收盘 | 256.57 元 |
| MA20 | 259.23 元 |
| MA60 | 271.70 元 |
| MA120 | 278.50 元 |
| RSI14 | 44.67 |

收盘价低于 MA20、MA60 和 MA120，且短期均线低于中期和长期均线，说明
样本末端仍处在中期偏弱结构。RSI14 为 44.67，位于中性区间，既不构成
超买，也没有形成明显的超卖反转信号。量价层面，近期换手率低于全周期
日均水平，尚未出现价格突破与放量同步的强确认。

## 5. 图表选择与理由

| 分析问题 | 图表 | 选择理由 |
|---|---|---|
| 单日开高低收与量能 | K 线 + 成交量 + MA | 最直接呈现价格路径、趋势和放量节点 |
| 中长期价格方向 | 收盘价折线 + MA20/60/120 | 降低单日噪声，便于比较趋势确认 |
| 下行风险 | 回撤面积图 | 直观展示距离历史峰值的位置和回撤深度 |
| 阶段性节奏 | 月度收益柱状图 | 比日收益更适合观察一个月的方向 |
| 年度比较 | 年度收益柱状图 | 只保留四个年度，适合直接比较 |
| 流动性变化 | 月度成交额柱状图 | 成交额受节假日和交易日数影响，月度汇总更稳定 |
| 精确读数与无障碍回退 | 区间行情表 | 图表之外仍可读取原始 OHLC 和成交指标 |

中国 A 股习惯使用红涨绿跌，因此图表采用红色表示上涨、绿色表示下跌，
同时保留正负号、K 线实体和文字读数，避免只靠颜色传达信息。

## 6. 分析结论

1. **四年整体近乎持平，但路径波动显著。** 全区间收益为 -1.97%，年化
   波动率却达到 30.80%，最大回撤为 -44.56%，典型的“终点接近起点、
   过程高度波动”特征。
2. **2024 年是主要修复年。** 在 2024-02 见到区间低点后，全年收涨
   43.79%，说明长期价格在下行后具备较强弹性，但前期持有者承受的回撤
   同样显著。
3. **2025 年价格高度活跃，却不是单边上涨。** 年内最高价达到
   422.47 元，年末收盘 302.63 元，年度仅上涨 5.03%；成交额与换手率
   同时放大，表明上涨和分歧并存。
4. **2026 年样本末端偏弱。** 截至 2026-10-27，年内下跌 15.22%，收盘
   位于三条主要均线下方，RSI14 处于中性区间，尚无放量突破确认。
5. **风险控制比单看收益更重要。** 46.25% 的日胜率意味着该样本中下跌
   天数多于上涨天数。若只依据年度收益判断，2025 年的正收益会掩盖其
   后半段回撤和较大的路径风险。

## 7. 方法边界

本报告只使用价格、成交量和由此计算的统计指标，不对财报、销量、行业
政策或公司公告做因果归因。均线、RSI 和波动率均为历史描述工具，不能
保证未来表现。所有结论用于课程实战演练，不构成投资建议。
