## 3. 金融业务场景讨论

### Agent

如果只画一条收盘价折线，会得到一个表面结论：“2023 年初约 262 元，
2026-10-27 约 257 元，四年几乎没涨。”这只回答了终点，无法解释过程。

比亚迪属于新能源汽车、动力电池与电子制造相关企业，股价同时受产品
周期、行业渗透率、价格竞争、成本、政策和市场风险偏好影响。即使不做
事件归因，价格数据本身也至少应拆成：

- **方向**：年度收益、区间收益、均线结构；
- **路径**：K 线、月度涨跌、阶段高低点；
- **风险**：年化波动率、最大回撤、回撤持续区间；
- **确认**：成交量、换手率与趋势指标。

### 共识落地

| 业务问题 | 对应分析证据 |
|---|---|
| 四年价格是否上涨 | 首尾收盘、年度收益 |
| 波动是否适合长期持有 | 年化波动率、最大回撤、日胜率 |
| 2025 年高点后发生了什么 | 回撤图、月收益、均线 |
| 2026 年末端趋势是否修复 | 收盘 vs MA20/60/120、RSI14、成交量 |
| 成交量是否支持价格运动 | K 线下方量能图、月度成交额 |

### Agent 判断

最终结论必须区分“期末收益”和“路径风险”。本数据全区间收益仅
`-1.97%`，但最大回撤达到 `-44.56%`，年化波动率为 `30.80%`。如果把
首尾接近持平解释为“低风险”，就会犯口径错误。

## 4. 可视化工具和图表选择

### Agent 方案

使用 Vue 3 承载交互界面，TDesign Vue Next 提供控件，ECharts 提供金融
图表，Excel 原生图表提供线下复现。三者职责不同：

| 工具 | 用途 | 不承担的职责 |
|---|---|---|
| TDesign Vue Next | 时间窗、日期、图表 N 型切换、开关、筛选、表格、分页、提示 | 不替代金融图表 |
| ECharts | K 线、成交量、均线、回撤、月/年收益图 | 不承担页面控件 |
| OpenPyXL | 格式化完整数据、指标、Excel 原生图表 | 不承担网页交互 |

### 图表讨论

候选图表包括普通折线、散点、K 线和面积图。最终选择：

1. **K 线 + 成交量**：保留开盘、收盘、最高、最低和量能，适合日频行情。
2. **收盘价 + MA20/60/120**：降低单日噪声，回答中期趋势是否确认。
3. **回撤面积图**：显示价格距历史峰值的损失，直接服务风险判断。
4. **月度收益柱状图**：观察阶段节奏，避免日收益过于密集。
5. **年度收益柱状图**：四个年度可直接比较。
6. **区间行情表**：提供精确数值和无障碍回退，不强迫用户只读颜色。

### 指标口径讨论

| 指标 | 采用口径 | 选择理由 |
|---|---|---|
| 价格 | 后复权收盘 | 跨年度比较不受除权除息跳空干扰 |
| 区间收益 | 末收盘 / 首收盘 - 1 | 与教材中的收益率定义一致 |
| 年化波动率 | 日收益样本标准差 × √252 | 可比较不同时间窗的风险 |
| 最大回撤 | 收盘相对运行峰值的最低跌幅 | 衡量实际持有路径中的下行风险 |
| MA | 20/60/120 日简单均线 | 短中长期各保留一条，避免过度拥挤 |
| RSI | RSI(14)，Wilder 平滑 | 判断超买超卖，但不单独作为买卖信号 |
| 日胜率 | 上涨日 /（上涨日 + 下跌日） | 描述收益分布，不把平盘算入 |
| 成交量 | 原始单位为手 | 图表换算万手，成交额换算亿元 |

### Agent 判断

拒绝使用“预测线”或“目标价”作为主图，因为用户要求的是历史走势分析，
没有提供预测模型、置信区间或未来基本面假设。也拒绝只做饼图；OHLC 和
时间序列不适合用占比图表达。

## 7. 代码、图表与结论的修正记录

### 7.1 拒绝直接采用生成的深色营销页

问题：技能默认方案是 OLED 深色和销售页结构，不符合工作台场景。

修正：保留设计智能中的精确数值字体、焦点和动效规则，覆盖为纸白、
信息密集、无 Hero 的分析工作台。记录在页面级覆盖文件中。

### 7.2 修正 TDesign Tabs 用法

第一版把选项数组传给 `tabs`，实际页面没有生成四个选项卡。

判断：图标和图形区域正常，但控件缺失，方案不可接受。

修正：MCP 文档对应 Vue Next 组件使用子面板。改为四个
`t-tab-panel` 后，Playwright 能点击“回撤”“月度收益”和“K 线”。

### 7.3 修正表格单元格运行时错误

浏览器验证发现控制台反复出现：

```text
TypeError: Cannot read properties of undefined (reading '涨跌幅')
```

定位：TDesign 表格把以列名命名的插槽同时用于表头渲染，表头上下文没有
`row`，导致读取失败。

修正：为涨跌幅、成交量、成交额、换手率设置独立 `cell` 插槽，避免列名
与表头上下文冲突。复查后控制台错误为 0。

### 7.4 修正移动端时间控件溢出

375 px 截图显示快捷时间按钮只显示前四个，需要内部横向滚动。

判断：页面没有横向溢出，但工作流不够直接。

修正：移动端允许快捷按钮换行，使 1 月、3 月、6 月、1 年、3 年和全周期
都可见。

### 7.5 修正 CSV 文件名日期

浏览器下载测试发现区间边界文本正确，但文件名起始日可能因 picker
日期对象转换少一天。

修正：导出文件名改为取实际筛选后的首末交易记录日期，与可见区间一致。
